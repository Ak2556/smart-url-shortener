Smart, modern, and minimalistic URL shortener built using **Next.js 15 (App Router)**, **TailwindCSS**, and **Vercel**.

---

## ✨ Features

- 🔗 Shorten long URLs instantly
- ✅ Copy-to-clipboard functionality
- 🔁 Track recent links in `localStorage`
- 📣 Toast feedback when copied
- 📦 Redirect support using dynamic `[slug]`
- 📱 Fully responsive UI
- 📊 Clean code, modular hooks, and components

---

## 🛠 Tech Stack

- **Next.js 15 (App Router)**
- **TailwindCSS**
- **TypeScript**
- **Framer Motion** for animations
- **QRCode.react** (optional)
